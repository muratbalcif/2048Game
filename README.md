# 2048 Modern Puzzle

Native 2048 game for Android (Kotlin/Jetpack Compose) and iOS (Swift/SwiftUI).

## Phase 0
- Define game rules and design system
- Bootstrap Android and iOS projects
- Establish build and test pipelines

## Game rules
4x4 board, 2048 target, swipe-to-merge, best score, undo, offline save.
