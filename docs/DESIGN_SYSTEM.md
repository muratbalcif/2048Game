# Design system — Modern Premium

Palette:
- Canvas: #FAF8F5
- Surface: #FFFFFF
- Ink: #24243A
- Muted text: #77778A
- Primary: #6657E8
- Accent: #FFB547
- Board: #E9E5E2
- Empty cell: #F5F1ED

Tile colors:
2 #FFF0DA; 4 #FFE0BA; 8 #FFB16E; 16 #FF866F;
32 #FF6D93; 64 #D879EC; 128 #67B8F4; 256 #43C5C2;
512 #6FCF97; 1024 #B9A0FF; 2048 #FFD15C.

Typography: system font (Android default sans / iOS SF), bold tabular numerals.
Radii: 24dp cards, 16dp tiles, 14dp buttons.
Spacing: 4/8/12/16/24/32.
Minimum touch target: 48dp Android, 44pt iOS.
Respect reduced motion, dynamic text, dark mode and contrast settings.

Screens: Game, Result dialog, Settings. Modes/Stats/Themes reserved for v2.
